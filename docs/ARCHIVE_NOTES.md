# Примечания к учебному архиву

## Происхождение

Основа коллекции — локальная папка `nstu`. Содержимое распределено по исходным семестрам без переименования предметов и вариантов. Исходники первой лабораторной второго семестра дополнены из существующего публичного репозитория `Assweg/1laba_2sem`.

Курсовой проект `crpted2` распакован из локального ZIP. Большой ZIP лабораторной по ИИ не публикуется: в архив включена уже распакованная папка с Notebook, данными, пояснениями и артефактом preprocessing.

## Статус материалов

- Для `RGR_2sem` исходники и отчёт РГР не найдены.
- Папка `3sem/Laba6` не содержит файлов.
- Каталога `4sem` в исходной папке нет. Маркировка семестров в старых репозиториях и локальных каталогах местами различается; исходные названия сохранены.
- В БСБД и ТиМП несколько каталогов являются вариантами одного проекта. Они сохранены по отдельности.
- Разделы `eltex` и `Library` — дополнительные материалы и сторонние заголовки.

## Конфигурация

Не включены локальные файлы пользователей, пароли из отдельных credential-файлов, VPN-профиль, SSH/TLS private keys и ключи шифрования БД, почтовые аккаунты, журналы и резервные копии. Для сетевого стенда `5sem/ТиМП/lab3` создайте собственные ключи, сертификаты и аккаунты.

В исходниках SQL, Compose и учебных примерах встречаются демонстрационные реквизиты. Их наличие нужно учитывать при локальном запуске и менять перед использованием стенда во внешней среде.

## Проверка публикации

Проверены состав публикуемых файлов, максимальный размер файла, ссылки в новых README и отсутствие распознаваемых приватных ключей и распространённых форматов access tokens в публикуемом содержимом. Это не полный аудит безопасности и не проверка всех документов на персональные данные.

Полная установка зависимостей, сборка проектов, запуск БД, повторное выполнение Notebook и сценарии атак в рамках публикации не выполнялись. Старые инструкции и `requirements.txt` сохранены как материалы соответствующих работ; доступность зафиксированных версий пакетов отдельно не проверялась.
