## Как пользоваться архивом

1. Выберите семестр и работу в таблице.
2. Откройте `README.md` внутри каталога: в нём есть ссылки на исходники и документы.
3. Для запуска отдельного проекта следуйте его инструкции и проверьте зависимости. Команды и пароли в исходных материалах относятся к учебным стендам.

Для локальной копии:

```bash
git clone https://github.com/Assweg/nstu.git
cd nstu
```

## Что сохранено

Сохранены исходные названия папок, варианты решений, PDF/DOCX-отчёты, таблицы и Notebook с результатами. Из архива курсовой извлечён код. Подробные старые инструкции доступны как `README_ORIGINAL.md` там, где вместо них добавлена навигация.

Установленные библиотеки (`node_modules`, виртуальные окружения Python), исполняемые файлы, временные файлы редакторов, локальные журналы и резервные копии не загружаются. VPN-профили, приватные ключи, ключи шифрования БД (включая исходные примеры) и файлы локальных учётных записей исключены. Для соответствующих стендов потребуется собственная конфигурация.

Публикация не является повторной проверкой всех лабораторных. Особенности архива и границы проверки описаны в [примечаниях](docs/ARCHIVE_NOTES.md). Перечень исходных файлов с SHA-256: [manifest.json](docs/manifest.json).
