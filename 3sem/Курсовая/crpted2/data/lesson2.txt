
Эти задачи лежат в основе безопасности многих криптосистем (RSA, Диффи-Хеллмана, ECC). Если их можно решать эффективно, то криптография на открытых ключах станет уязвимой.  

---

1.1. Алгоритмы факторизации  
Факторизация — разложение числа на простые множители. Для криптографии важно, что:  
RSA основан на сложности факторизации  n = p \cdot q .  
Если научиться быстро факторизовать, RSA сломается.  

Переборные методы  
Пробное деление – проверка делимости на все простые числа до sqrt{n}.  
Сложность: неприменимо для больших чисел.  

Вероятностные методы  
Метод Полларда (ρ-алгоритм)  
Основан на поиске циклов в последовательности \( x_{i+1} = f(x_i) \mod n \).  
 

Общее решето числового поля (GNFS)  
Самый эффективный метод для больших чисел (>100 цифр).  
Использует алгебраические структуры для поиска соотношений.  

---

1.2. Дискретное логарифмирование  
Задача: Найти x в уравнении  a^x \equiv b \pmod{p}.  

Алгоритмы для произвольных групп  
Baby-step Giant-step (Шаг младенца – шаг великана)  
- Таблица "малых шагов" ( a^i \mod p ) и "больших шагов" ( b \cdot a^{-kj} \mod p ).  

Алгоритм Полларда (ρ для логарифмов)  
Аналог ρ-метода для факторизации.  


Алгоритмы для мультипликативной группы \( \mathbb{Z}_p^* \)  
Алгоритм Полига-Хеллмана  
- Эффективен, если порядок группы p-1 имеет только малые простые делители.  
- Использует разложение p-1 и КТО.  

Index Calculus (метод индексного исчисления): Аналог квадратичного решета для логарифмов.  

Дискретный логарифм в других группах  
Эллиптические кривые (ECC): Нет эффективных субэкспоненциальных алгоритмов → ECC безопаснее при меньших ключах.  


---

1.3. Квантовые алгоритмы (угроза будущему)  
Алгоритм Шора:  
Позволяет факторизовать числа и решать дискретный логарифм за полиномиальное время.  
Угроза для RSA, Диффи-Хеллмана и ECC.  
Пока требует тысяч кубитов (недостижимо для практических атак).  

---

Заключение  
Факторизация и дискретный логарифм — сложные задачи, на которых держится безопасность RSA, Диффи-Хеллмана и ECC.  
GNFS и Index Calculus — лучшие классические алгоритмы, но они субэкспоненциальны.  
Квантовые компьютеры могут всё сломать (алгоритм Шора), но пока это далёкая угроза.
