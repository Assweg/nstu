# Локальные ключи шифрования

В исходном каталоге примеров находились готовые ключи, поэтому они исключены из публичной копии.

Для выполнения лабораторной подготовьте собственные файлы в соседнем каталоге `secrets/`:

- `lr3_sym_key.txt` — симметричный ключ;
- `lr3_master_kek.txt` — ключ защиты ключей;
- `lr3_pgp_public.asc` и `lr3_pgp_private.asc` — собственная пара PGP-ключей;
- `wal_archive_pass.txt` — пароль архива WAL для ЛР4, если его использует Compose.

Скрипт `scripts/ensure_lr3_secrets.sh` рассчитан на копирование готовых файлов из `secrets.example/`. В публичной копии их нет: подготовьте собственные ключи до запуска стенда. Не добавляйте их в Git.
