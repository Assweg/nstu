# Пошаговая инструкция: Подключение к базе данных в pgAdmin

## Шаг 1: Вход в pgAdmin

1. Откройте браузер и перейдите по адресу: **http://localhost:5050**
2. Введите учетные данные:
   - **Email**: `admin@dubbing.studio`
   - **Password**: `admin123`
3. Нажмите "Login"

## Шаг 2: Регистрация сервера

После входа вы увидите интерфейс pgAdmin с левой панелью, где находится дерево объектов.

### 2.1. Откройте меню регистрации сервера

1. В левой панели найдите раздел **"Servers"** (обычно в самом верху)
2. **Правой кнопкой мыши** нажмите на **"Servers"**
3. В контекстном меню выберите: **"Register"** → **"Server..."**

Откроется окно "Register - Server" с несколькими вкладками.

## Шаг 3: Настройка подключения

### Вкладка "General"

1. Перейдите на вкладку **"General"** (открыта по умолчанию)
2. Заполните поля:
   - **Name**: `Dubbing Studio DB`
   - **Server group**: оставьте `Servers` (по умолчанию)
   - **Comments**: `База данных студии дубляжа - ЛР1 и ЛР2` (опционально)

### Вкладка "Connection"

1. Перейдите на вкладку **"Connection"**
2. Заполните следующие поля:

   | Поле | Значение | Примечание |
   |------|----------|------------|
   | **Host name/address** | `dubbing-studio-db` | ⚠️ **Важно**: Это имя сервиса из docker-compose.yml, НЕ localhost! |
   | **Port** | `5432` | Стандартный порт PostgreSQL |
   | **Maintenance database** | `dubbing_studio` | Имя базы данных |
   | **Username** | `postgres` | Пользователь БД |
   | **Password** | `secure_password_123` | Пароль пользователя |
   | **Save password?** | ✅ Отметьте галочку | Чтобы не вводить пароль каждый раз |

   ⚠️ **Важно**: В поле "Host name/address" используйте `dubbing-studio-db` (имя сервиса Docker), а не `localhost`! Это нужно потому, что pgAdmin работает внутри Docker-сети и подключается к PostgreSQL через внутреннее имя сервиса.

### Вкладка "Advanced" (опционально)

1. Перейдите на вкладку **"Advanced"** (необязательно)
2. В поле **"DB restriction"** можно указать `dubbing_studio`, чтобы видеть только эту базу данных
3. Или оставьте пустым, чтобы видеть все базы данных

### Вкладка "SSL" (опционально)

- Оставьте настройки по умолчанию
- Режим SSL: `Prefer` (по умолчанию)

## Шаг 4: Сохранение

1. После заполнения всех полей нажмите кнопку **"Save"** в нижней части окна
2. Окно закроется, и сервер появится в дереве объектов слева под разделом "Servers"

## Шаг 5: Проверка подключения

1. В левой панели разверните **"Servers"**
2. Вы увидите ваш новый сервер: **"Dubbing Studio DB"**
3. Разверните сервер (нажмите на стрелку слева от имени)
4. Разверните **"Databases"**
5. Разверните **"dubbing_studio"**
6. Вы увидите схему **"Schemas"**

## Шаг 6: Просмотр базы данных

После успешного подключения вы сможете:

1. **Просматривать схемы**: разверните "Schemas" → вы увидите схемы: `app`, `ref`, `audit`, `stg`
2. **Просматривать таблицы**: разверните схему (например, `app`) → "Tables" → список таблиц
3. **Выполнять SQL-запросы**: 
   - Правой кнопкой на базе данных или таблице → "Query Tool"
   - Или используйте иконку "Query Tool" на панели инструментов
4. **Просматривать функции**: разверните схему → "Functions" → список функций
5. **Просматривать данные**: правой кнопкой на таблице → "View/Edit Data" → "All Rows"

## Пример: Просмотр журнала вызовов функций

1. Разверните: **Servers** → **Dubbing Studio DB** → **Databases** → **dubbing_studio** → **Schemas** → **audit** → **Tables**
2. Найдите таблицу **"function_calls"**
3. Правой кнопкой на **"function_calls"** → **"View/Edit Data"** → **"All Rows"**
4. Или откройте Query Tool и выполните:
   ```sql
   SELECT * FROM audit.function_calls 
   ORDER BY call_time DESC 
   LIMIT 20;
   ```

## Устранение проблем

### Ошибка подключения

Если вы видите ошибку подключения:

1. **Проверьте, что контейнеры запущены**:
   ```bash
   docker ps
   ```
   Должны быть запущены оба контейнера: `dubbing_studio_postgres` и `dubbing_studio_pgadmin`

2. **Проверьте имя хоста**: используйте `dubbing-studio-db`, а не `localhost`

3. **Проверьте пароль**: убедитесь, что используете правильный пароль `secure_password_123`

4. **Проверьте логи контейнера**:
   ```bash
   docker logs dubbing_studio_postgres
   ```

### Сервер не появляется в списке

- Убедитесь, что вы нажали кнопку "Save" после заполнения формы
- Проверьте, что нет ошибок валидации (красные поля)

### Не видно базы данных

- Убедитесь, что база данных инициализирована: выполните `./run_docker.sh init`
- Проверьте, что скрипты ЛР1 выполнены

## Полезные функции pgAdmin

- **Query Tool**: для выполнения SQL-запросов
- **Dashboard**: для просмотра статистики БД
- **Backup/Restore**: для резервного копирования
- **ERD Tool**: для визуализации схемы базы данных
- **Statistics**: для просмотра статистики по таблицам и индексам
