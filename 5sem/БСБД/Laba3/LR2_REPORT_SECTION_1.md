# Описание пункта 1: SECURITY DEFINER-функции

## Введение

В качестве чувствительных операций, для которых были реализованы SECURITY DEFINER-функции, были выбраны:

1. **Создание контракта с актёром** (`app.create_contract`) — операция создания ключевого бизнес-объекта, содержащего конфиденциальные данные (сумма контракта, условия). Требует повышенных привилегий для проверки целостности данных и логирования.

2. **Обновление зарплаты в контракте** (`app.update_contract_salary`) — операция изменения конфиденциальных финансовых данных. Требует строгой валидации и контроля доступа для предотвращения несанкционированных изменений.

3. **Регистрация сессии записи** (`app.register_recording_session`) — бизнес-транзакция, регистрирующая сессию записи дубляжа. Требует проверки статуса контракта и валидации параметров сессии для обеспечения целостности бизнес-процессов.

Все функции реализованы с использованием модификатора `SECURITY DEFINER`, что позволяет выполнять их с правами владельца функции (роль `app_owner`), при этом вызывать их могут пользователи с ограниченными правами (роли `app_writer`, `studio_manager`). Это обеспечивает принцип наименьших привилегий: пользователи получают доступ только к необходимым операциям, не имея прямых прав на изменение таблиц.

Также в каждой из функций реализована валидация данных для корректной вставки. Соотношение таблицы и прописанных в ней правил представлено в таблице 1.1.

**Таблица 1.1 ‒ Валидация данных в функциях**

| Название функции | Проверяемые данные | Описание проверки |
|-----------------|-------------------|-------------------|
| `app.create_contract` | `p_project_id` | Проверка существования проекта в таблице `app.projects` |
| | `p_actor_id` | Проверка существования и активности актёра в таблице `app.actors` (поле `is_active = true`) |
| | `p_contract_number` | Проверка уникальности номера контракта в таблице `app.contracts` |
| | `p_contract_number` | Проверка обязательного поля: не NULL и не пустая строка |
| | `p_role_description` | Проверка обязательного поля: не NULL и не пустая строка |
| | `p_salary_amount` | Проверка, что сумма контракта не NULL и больше 0 |
| | `p_signed_date`, `p_end_date` | Проверка корректности дат: `end_date >= signed_date` (если обе даты указаны) |
| `app.update_contract_salary` | `p_contract_id` | Проверка существования контракта в таблице `app.contracts` |
| | `p_new_salary_amount` | Проверка, что новая сумма не NULL и больше 0 |
| | `p_new_salary_amount`, `v_old_salary` | Проверка, что новая сумма отличается от старой |
| | Статус контракта | Проверка, что контракт не завершён (`status NOT IN ('cancelled', 'completed')`) |
| `app.register_recording_session` | `p_contract_id` | Проверка существования контракта в таблице `app.contracts` |
| | Статус контракта | Проверка, что контракт активен (`status = 'active'`) |
| | `p_session_date` | Проверка, что дата сессии не в прошлом более чем на 1 день |
| | `p_duration_hours` | Проверка, что длительность сессии в диапазоне от 0 до 24 часов |
| | `p_studio_location` | Проверка обязательного поля: не NULL и не пустая строка |

## Реализация

Все функции созданы с использованием следующих характеристик:

- **Язык:** PL/pgSQL
- **Модификатор безопасности:** `SECURITY DEFINER`
- **Безопасный search_path:** `SET search_path = app, ref, audit, public`
- **Логирование:** Каждый вызов функции автоматически записывается в таблицу `audit.function_calls` с параметрами, результатом выполнения и временем выполнения
- **Обработка ошибок:** Все ошибки валидации логируются с понятными сообщениями и пробрасываются вызывающему коду

Функции доступны для выполнения ролям `app_writer` и `studio_manager`, что позволяет пользователям с ограниченными правами выполнять чувствительные операции под контролем системы безопасности.

## Пример использования

```sql
-- Создание контракта
SELECT app.create_contract(
    p_project_id := 1,
    p_actor_id := 1,
    p_contract_number := 'CNTR-2024-100',
    p_role_description := 'Главный герой',
    p_salary_amount := 50000.00
);

-- Обновление зарплаты
SELECT app.update_contract_salary(
    p_contract_id := 1,
    p_new_salary_amount := 60000.00,
    p_reason := 'Повышение за хорошую работу'
);

-- Регистрация сессии
SELECT app.register_recording_session(
    p_contract_id := 1,
    p_session_date := CURRENT_DATE + INTERVAL '1 day',
    p_session_time := '10:00:00',
    p_studio_location := 'Студия А, Москва',
    p_duration_hours := 4.5
);
```
